# Этап 2 — детали вакансии и быстрый фильтр

**Цель:** в Telegram приходят только вакансии, которые проходят правила пользователя, с полным описанием в таблице. Мусор отсеивается бесплатно, без LLM.

Правила и их происхождение — CLAUDE.md §7.

## Как устроено (W1 после «Is new»)

```
Is new → Blacklist (все строки таблицы blacklist, один раз)
       → Filter search    правила по данным выдачи → status new | rejected, reasons
       → Insert           все вакансии пишутся в таблицу
OK?    → Pending new      все строки status = new (ветка ниже вставки — выполняется после неё)
       → Candidates       строки этого сбора — все, хвост прошлых — до 25 за сбор, свежие первыми
       → Vacancy page     страница вакансии (по одной, пауза 3 с)
       → Parse vacancy    описание, навыки, тест, ТК/ГПХ + правила по описанию → detailed | rejected
       → Update           запись обратно по id
```

Очередь страниц (19.10.2026): раньше страницы открывались только у вставленных этим сбором, и сбор, упавший посреди
страниц, оставлял строки `new` навсегда. Теперь их добирают следующие сборы; хвост виден в «🔎 Сбор» строкой
«📥 Из очереди: …».

- Сообщения в Telegram с этапа 3 шлёт W2: карточка на каждую `detailed` + сообщение о сборе, где отсеянные перечислены с причинами: «🚫 Название — причина» (`docs/stages/stage-3.md`). Отсеянные видны в таблице `vacancies` (`status = rejected`, `reasons`).
- Страница вакансии не открылась → вакансия всё равно `detailed` с текстом в `error`: нейросеть оценит её по фрагменту из выдачи, в карточке ⚠️.
- Код: `n8n/w1-collector/filter-search.js`, `parse-vacancy.js`.
- AI-вакансии (07.10.2026, `n8n/shared/ai.js`: AI, ИИ, LLM, GenAI, GPT, RAG, агенты, нейросети — в названии, на странице ещё и в навыках) берём на любом языке (19.10.2026; до того — только на JS/TS, остальные отсекались «AI не на JS/TS»): правило «бэкенд» их не режет, «нет React и Vue» — тоже, Python в названии AI-вакансии «чужим стеком» не считается. Ruby, C#/.NET, Java, Go в названии режутся и у них.
- «Только из РФ» (19.10.2026) не срабатывает, если в той же части фразы перед совпадением отрицание: «нельзя находиться в РФ», «не только из России», «не обязательно быть резидентом РФ».
- junior: «intern» — целым словом (Internal, International — не стажёры).

## Чёрный список

Таблица `blacklist` в n8n (Overview → Data tables → blacklist).

| company | comment |
|---|---|
| `Ozon Tech` | точное название компании, как в карточке вакансии на hh |
| `2180` | id компании на hh |

- `company` — **точное** название компании (регистр, лишние пробелы и форма организации — ООО, АО, ПАО… — не важны) **или** её id на hh (только цифры, видно в ссылке `hh.ru/employer/<id>`).
- Подразделения на hh — отдельные названия: «Альфа-Банк» не отсекает «Альфа-Банк. ИТ-специалисты», их надо добавлять отдельной строкой.
- Стартовый список пользователя (07.10.2026, 26 компаний) — `n8n/blacklist.json`, загружается `node scripts/n8n-api.mjs blacklist-seed` (дописывает только отсутствующих). Дальше можно править прямо в UI.
- Действует на следующих запусках W1; уже записанные вакансии не пересматриваются.

## Правило поменялось — перепроверить отсеянных

```bash
node scripts/n8n-api.mjs sweep --no-search --dry   # что вернётся в очередь: отсеянные за 30 дней (--days N), которых
                                                   # нынешние правила по выдаче пропускают
node scripts/n8n-api.mjs sweep --no-search         # вернуть их в status new: страницы откроют следующие сборы W1
node scripts/n8n-api.mjs sweep --dry               # то же + поиск hh за 30 дней (новые для базы) и удаление бэкфилла seen
```

- Отсеянные причинами со страницы («в архиве», «только из РФ», «нет React и Vue») не перепроверяются — их пересмотрит
  только страница; ушедшее правило «AI не на JS/TS» (19.10.2026) — перепроверяется.
- Строки new — очередь W1: строки сбора — все, хвост — до 25 за сбор; в «🔎 Сбор» — строка «📥 Из очереди».
- Пока идёт догон, в runs запись `kind = sweep`, `status = running`: W1 «Busy» пропускает сбор (1–2 мин).
- До 19.10.2026 были команды `recheck <правило>` и `requeue <дни>`: они удаляли строки и видели только последнюю
  суточную выдачу. 07.10.2026 так вернули Vue-вакансии: правило «Vue/Angular» стало «Angular». 19.10.2026 — разовый
  `sweep` после ослабления правил (AI на любом языке, порог откликов 0, «без опыта» выключено).
