# Этап 3 — оценка нейросетью и кнопки в Telegram (теневой режим)

**Цель:** нейросеть ставит каждой вакансии, прошедшей фильтр, решение apply / maybe / skip с причиной. Пользователь отвечает кнопками, и неделю решения сверяются.

Решения пользователя (07.10.2026) — CLAUDE.md §7 «Решает нейросеть».

## Как устроено

```
W1 Collector (днём каждые 30 мин, ночью каждые 2 ч)  … → Parse vacancy → Update: status = detailed → Score job → W2
W2 Score     (вызывает W1)     Pending: строки detailed (до 40, старые первыми)
                                → Resume (docs/resume.md) → Build prompt
                                → Claude? ─ да ─→ Claude ─┐
                                           └ нет → Gemini ─┴→ Parse verdict
                                → Format card → Send card (кнопки) → Card sent → Save cards: status = waiting
             своя ветка от триггера (выполняется последней, даже если оценивать нечего):
                                Summary → Send summary (сообщение о сборе, итог, тревоги) → Live report → Delete report
W3 Telegram  (вебхук)           Telegram Trigger → Route
                                → кнопка: Vacancy → Apply choice → Save choice → Answer → карточка перерисована
                                          → решение не совпало с нейросетью → «Почему?» → Save ask
                                → ответ на «Почему?»: Reason row → Save reason → «✍️ Записал причину»
```

- Код: `n8n/w2-score/*.js`, `n8n/w3-telegram/*.js`, общий код карточки — `n8n/shared/card.js` (подключается строкой `// @include`).
- Страница вакансии не открылась → W1 всё равно ставит `detailed`, нейросеть оценивает по фрагменту из выдачи, в карточке ⚠️.

- После нажатия кнопки исчезают, в карточке строка `👤 ✅ Откликнусь` и кнопка `↩️ Изменить`.
- «🚫 В ЧС» — компания уходит в чёрный список (таблица `blacklist`), карточка — ❌ с причиной «чёрный список», без «Почему?». Убрать — ⚙️ → 🧹 Фильтр → «🚫 Чёрный список» (`docs/settings.md`).
- «📨 Уже откликался» — откликался до бота: письмо не пишется, статус `applied` без `applied_at`, в карточке `👤 📨 Откликался раньше`; «Почему?» не спрашивается, в теневой режим не идёт.
- Твоё решение не совпало с нейросетью → бот отвечает на карточку: «Почему?». Ответь на это сообщение (reply) одной фразой — причина ляжет в `my_reason`. Можно не отвечать.

## Теневой режим

Карточка приходит на каждую оценённую вакансию, включая skip. После 50 твоих оценок (примерно неделя) — отчёт: где нейросеть совпала с тобой, где нет и почему (колонки `decision`, `my_decision`, `my_reason`, `prompt_v` — версия промпта). Потом решаем, выключать ли режим: с 07.10.2026 это кнопка в боте (⚙️ → 🤖 Нейросеть → «Теневой: выкл»). Тогда skip без карточек — в итоге после сбора и в меню на вкладке ❌.

## Нейросеть

- Сейчас: **Gemini 3.5 Flash-Lite**, бесплатный тариф. Модель — `GEMINI_MODEL` в `.env` (по умолчанию `gemini-3.5-flash-lite`, закреплена: алиас `…-latest` сменил бы модель посреди теневого режима). Замер 07.10.2026: ~2,3 тыс. токенов на вакансию, ответ ~1,2 с.
- Запросы — не чаще одного в 7 с, до 40 вакансий за запуск.
- Лимит кончился (HTTP 429) → тревога в Telegram, вакансии остаются `detailed` и оценятся в следующий запуск.
- Временный сбой нейросети (HTTP 5xx, например Gemini 503 «высокий спрос», таймаут 60 с, обрыв сети — `outcome = retry`) → вакансии остаются `detailed` и оценятся в следующий запуск; в чат — строка в тихом сообщении о сборе, без звука. Тревога со звуком — только если нейросеть не отвечает 3 запуска подряд (счётчик `llmFails` в static data W2, сбрасывается любой оценкой), потом раз в 8 запусков. Ошибка ключа или доступа (HTTP 4xx, кроме 429) — сразу тревогой. Тесты — `node --test scripts/test-w2.mjs`.
- **Переключение на Claude Haiku 4.5:** ключ с https://console.anthropic.com → в `.env` строка `ANTHROPIC_API_KEY=…` → `scripts/deploy.sh` → в боте ⚙️ → 🤖 Нейросеть → «Модель: Claude» (с 07.10.2026; `LLM_PROVIDER` больше не читается).
- Бесплатный Gemini может использовать запросы для обучения моделей Google; в промпт уходит резюме целиком (решение пользователя).

## Калибровка промпта (07.10.2026)

На 19 вакансиях (4 проверочных + бэкфилл 3 дней) Flash-Lite ошибался так — и промпт это теперь оговаривает явно:

- fullstack с сильным .NET → skip «нет опыта бэкенда» → правило: любой fullstack — maybe, нехватка опыта в бэкенде не повод для skip;
- компания из США → skip «риск ночных часов» → skip только при прямом требовании (EST, PST);
- льготы для РФ (ИТ-ипотека, бронь), ТК РУз → skip «нужно быть резидентом» → косвенные признаки — maybe;
- React Native как дополнительная задача → skip «мобильная разработка» → skip, только если мобильная разработка — основная работа;
- «регионы публикации» не включают Таиланд → skip → поле переименовано: «где размещена на hh (не требование к месту жительства)».

Локальная проверка решений: `node scripts/run-code-node.mjs n8n/w2-score/build-prompt.js …` → запросы к Gemini из скрипта (ключ из `.env`, не печатать).

## Туннель для кнопок

Telegram сообщает о нажатии кнопки запросом на публичный HTTPS-адрес. Локальному n8n его даёт ngrok — контейнер `job-hunter-ngrok` рядом с n8n (`docker-compose.yml`, профиль `tunnel`).

- Наружу — только `/webhook/*` и только с адресов Telegram (`ngrok/policy.yml`). Интерфейс n8n остаётся на `http://localhost:5678`.
- Telegram Trigger проверяет секретный заголовок запроса и принимает только твой чат (`TG_CHAT_ID`).
- Бесплатный ngrok: один постоянный домен, 20 000 запросов в месяц — для кнопок с запасом.

## Настройка (один раз)

1. Ключ Gemini: https://aistudio.google.com/apikey → **Create API key**.
2. ngrok: https://dashboard.ngrok.com/signup → **Your Authtoken** и **Domains** (домен вида `name.ngrok-free.app`).
3. В `.env`:
   ```
   GEMINI_API_KEY=…
   NGROK_AUTHTOKEN=…
   NGROK_DOMAIN=name.ngrok-free.app
   ```
4. Деплой (делает Claude):
   ```bash
   node scripts/n8n-api.mjs migrate          # колонки decision, llm_reason, my_decision, …
   scripts/deploy.sh --publish               # WEBHOOK_URL + туннель, credentials, W1–W4
   ```
