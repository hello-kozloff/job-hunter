# Этап 5 — ежедневная сводка и страж

**Цель:** каждое утро короткая сводка за прошедший день сбора; если система не работает (Mac спит, Docker на паузе, n8n упал), внешний страж пишет в Telegram сам.

> С 13.10.2026 сводку W6 запускают «часы» W8 в 10:00 по местному, а не cron 06:00 МСК: так она идёт по поясу человека и приходит после сна Mac (`docs/onboarding.md`, часть B).

Решения пользователя (07.10.2026):

| Вопрос | Решение |
|---|---|
| Когда | 10:00 по Таиланду (06:00 МСК) — итог прошедших суток |
| Что | воронка, хвосты, сбои, прогресс теневого режима |
| Звук | без звука; со звуком — только если есть сбои |
| Хвосты | только количество |
| Карточки без решения | через 3 дня — «⌛ устарела», кнопки убираются |
| Закрытые вакансии | раз в день хвосты проверяются на hh; закрыта — «🔒 закрыта на hh», кнопки убираются у карточки и письма |
| Страж | healthchecks.io, тревога в Telegram через их бота, если пропущен хотя бы 1 сбор; с 07.10.2026 (сбор днём раз в 30 мин) — если сбора нет ~1 час: днём 2 пропуска подряд, ночью 1 |
| 50 оценок | сводка напоминает «пора разбирать», разбор делаем вместе с Claude; счёт — с метки «🔄 Теневой заново» (19.10.2026, `llm.shadow_since`) |
| Еженедельный отчёт | не нужен |

## Сводка

```
☀️ Сводка за сутки · 08.10
🔎 Новых вакансий: 37 → фильтр отсеял 18 (> 3000 откликов 8 · чёрный список 4 · Angular 1)
🤖 Оценено: 18 — 🟢 6 · 🟡 7 · 🔴 5
👤 Твои решения: ✅ 7 · 🤔 2 · ❌ 1 · 📨 отправлено 2
⏳ Хвосты: без решения 9 · ✅ без отклика 5
⌛ Устарели: 1 · 🔒 закрылись на hh: 2
🧪 Теневой режим с 19.10: 10/50, совпало 8 (80%)    ← без метки сброса — «🧪 Теневой режим: …» по всем карточкам
⚙️ Сборов 29 из 29, ошибок нет, туннель работает    ← или «⚠️ Сбои: …» (тогда со звуком)
```

Сбои: сборов меньше, чем по расписанию W1 (29 за сутки; считаются записи журнала `runs` по расписанию до «сейчас − 10 мин» — сбор в 06:00 идёт одновременно со сводкой), ошибки запусков (по workflow), туннель не отвечает 403 снаружи, вакансии ждут оценки нейросетью дольше 30 минут, нет данных о запусках.

## Как устроено

```
W6 Summary  Schedule 0 6 * * * МСК (+ Manual) → All rows → Plan
  ├ Expire rows → Card: expired → Expired done → Save expired           (status = expired)
  ├ Check candidates → Vacancy page (hh, 3 с) → Archive status
  │     ├ Card: archived → Archived done → Save archived                 (status = archived)
  │     └ Has letter? → Letter: archived
  ├ Runs (журнал сборов) → Executions (публичный API n8n: ошибки) → Tunnel (https://<NGROK_DOMAIN>/ → 403)
  │     → Summary → Send summary
  ├ Cleanup → Save stripped        описания отработанных вакансий старше 30 дней (строка остаётся для дедупа)
  └ Delete old runs                журнал сборов старше 90 дней
W1 Collector  OK? → HC ping? → HC ping (GET $env.HC_PING_URL) — сигнал стражу после успешного поиска
W7 Bot menu   ⚙️ → 🕐 Сбор: расписание поменялось → HC sync (API healthchecks: новый OnCalendar и grace, пауза)
```

- Код: `n8n/w6-summary/*.js`; разбор страницы hh — общий с W1: `n8n/shared/hh.js`.
- Колонка `card_at` — когда W2 отправил карточку (от неё считаются 3 дня). У старых строк — `createdAt`.
- Ключ публичного API n8n — credential «n8n API» (`jobHunterN8nApi1`), права `execution:list`, `execution:read`.

## Настройка (один раз)

1. **Ключ API n8n** (делает Claude):
   ```bash
   node scripts/n8n-api.mjs api-key | docker exec -i job-hunter-n8n sh -c \
     'cat > /tmp/c.json && n8n import:credentials --input=/tmp/c.json; rm -f /tmp/c.json'
   ```
2. **healthchecks.io** (пользователь):
   - https://healthchecks.io → бесплатный аккаунт → **Add Check**: Name `job-hunter W1`; Schedule **OnCalendar** — две строки (= расписание W1), Server's Time Zone **Europe/Moscow** (тот же пояс и в конце строк):
     ```
     07..17:00,30 Europe/Moscow
     00,02,04,06,18,20,22:00 Europe/Moscow
     ```
     Grace Time **50 минут** (нет на слайдере — 45; ровно 60 не ставить: тревога совпадёт со следующим сбором). Предпросмотр должен показать днём каждые 30 минут по МСК (13:00, 13:30, 14:00…). Настроено пользователем 07.10.2026. До 07.10.2026 было Cron `0 9-21/2 * * *`, grace 30 минут;
   - **Integrations → Telegram** → @HealthchecksBot → Start;
   - Ping URL → `.env`: `HC_PING_URL=https://hc-ping.com/…`;
   - с 07.10.2026 расписание меняется в боте (⚙️ → 🕐 Сбор), и страж обновляется сам через API. Для этого **Settings → API Access → Create API key** (read-write) → `.env`: `HC_API_KEY=…` → деплой (`docs/settings.md`).
3. Деплой: `node scripts/n8n-api.mjs migrate && scripts/deploy.sh --publish`.

- страж прислал тревогу, когда Mac спал во время сбора (можно проверить: закрыть крышку на 3 часа днём).
