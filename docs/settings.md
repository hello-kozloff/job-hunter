# Настройки из бота (⚙️)

**Цель:** часть настроек системы меняется кнопками в Telegram, без правки кода и деплоя.

Решения пользователя (07.10.2026):
- в первой версии — разделы «Сбор», «Поиск и фильтр», «Нейросеть»; «Уведомления» — вторым шагом;
- страж healthchecks.io при смене расписания обновляется через свой API.

## Как устроено

- **Хранилище** — таблица `settings` (`name`, `value_json`). В ней только то, что пользователь поменял. Пустая таблица — значения по умолчанию, то есть поведение до появления настроек. Деплой таблицу не трогает.
- **Схема** — `n8n/shared/settings.js`:
  - `SETTINGS` — имя, значение по умолчанию, допустимые значения;
  - `loadSettings($('Settings').all())` — значения с учётом таблицы; значение не из списка заменяется значением по умолчанию;
  - `nextSetting(name, value)` — следующее значение по кругу (кнопка «▸»);
  - `scheduleFrom(settings)` — расписание для `n8n/shared/schedule.js`.
- **Чтение** — нода «Settings» (Data Table Get, все строки, один раз за запуск) в W1, W2, W5, W6, W7, W8, W9, W11, W13; хелпер `settingsNode` в `scripts/build-workflows.mjs`.
- **Запись** — W7: «Setting change» (следующее значение) → «Save setting» (upsert по `name`). Панель после нажатия показывает новое значение. Профиль пишут W11 (онбординг, ⚙️ → 👤) и W13 (резюме после правок, `resume.history`).

**Робот-отклик** (`apply.*`, этап 6, `docs/stages/stage-6.md`): раздел ⚙️ → 🚀 Робот — вкл/выкл, пауза, лимит в день, темп,

Автоотклик (6.1c, 20.10.2026) запускается и останавливается не здесь, а панелью «🤖 Автоотклик» под полем ввода; ▶️ заодно
включает робота и снимает паузу (`setting-change.js`: одно нажатие — несколько строк).

**Спорные случаи** (`llm.cases`): решение пользователя 07.10.2026 — список текстом, а не кнопками.
- **Ввод:** ✏️ присылает вопрос с текущим списком, ответ — новый список «случай: решение» через запятую; он заменяет прежний целиком.
- **Формат:**
  - решение — apply, maybe или skip (можно 🟢 🟡 🔴, «откликнусь», «возможно», «мимо»);
  - между случаем и решением — «:», «=» или тире;
  - если в описании нужна запятая — случаи через «;» или с новой строки;
  - «-» — очистить список; до 20 случаев, описание — 2–80 знаков.
- **Пример:** `Vue без React: apply, fullstack на Node: apply, Angular: maybe`.
- **Встроенные случаи** (`BUILTIN_CASES` в `n8n/shared/settings.js`): Vue без React (vue, nuxt…), fullstack, AI на JS/TS (ai…), React Native (rn). Их подробные формулировки — в промпте:
  - другое решение — поправка с той же формулировкой;
  - случая нет в списке — поправка «особого правила нет, решай по общим правилам»;
  - убран «AI на JS/TS» — пропадает и подсказка к AI-вакансиям.
- **Новые случаи** уходят в промпт как написаны: нейросеть понимает описание.

**Правила нейросети** — `n8n/w2-score/build-prompt.js`.
- Всё, что отличается от списка по умолчанию, дописывается в промпт блоком «Поправки кандидата — важнее правил выше…». Со списком по умолчанию промпт байт в байт прежний (проверено на 8 вакансиях).
- `prompt_v` — хеш текста промпта без резюме, пишется в строку при отправке карточки. По нему теневой режим разбирается отдельно для каждой версии промпта.
- Claude требует `ANTHROPIC_API_KEY` в `.env` и деплой. Без ключа оценка с Claude упадёт с ошибкой, панель об этом предупреждает.

**Списки слов** (✏️): бот присылает вопрос, ответ на него — новый список через запятую, он заменяет прежний целиком. W3 «Route» узнаёт вопрос по началу текста (`SETTING_PROMPTS` в `n8n/shared/menu.js`). Слово: буквы, цифры, пробел и `. + # ' -`, до 30 знаков, `*` в конце — любое окончание; списков до 40 слов. Скобки и кавычки запрещены — они сломали бы язык запросов hh. Слово с пробелом уходит в запрос в кавычках. Стоп-слова ищутся целым словом, с границами для кириллицы.

**Правила фильтра** (`FILTER_RULES`, кнопки ✅ / ◻️): без опыта, junior/стажёр, Angular, Lead/архитектор, стоп-слова, чужой стек, бэкенд, чёрный список, только из РФ, нет React и Vue. «В архиве» не выключается. Порог откликов — отдельная настройка: 0 — не отсекать.

**Чёрный список** — таблица `blacklist`, как раньше:
- «🚫 В ЧС» на карточке вакансии (в ленте и на панели) записывает компанию с комментарием «кнопка «🚫 В ЧС» дата · hh id · вакансия», а карточку делает ❌ с причиной «чёрный список», без вопроса «Почему?»;
- в ⚙️ → 🧹 Фильтр → «🚫 Чёрный список» — список с командами `/bl<id>`: команда спрашивает подтверждение и убирает компанию.

Слоты выровнены по полуночи МСК, шаг сетки — 15 минут. По умолчанию получается 29 сборов в сутки: днём 07:00–17:30 каждые 30 мин, ночью 18, 20, 22, 00, 02, 04, 06.

## Расписание: «часы» W8 Clock

У Schedule Trigger cron зашит в workflow: прочитать его из таблицы нельзя, а переписывать workflow через API — это расхождение с git. Поэтому:

- **W8 Clock** тикает каждые 15 мин (`*/15 * * * *`, `misfirePolicy: coalesce`), цепочка: Settings → «Due» → W1 (без ожидания).
- **«Due»** (`n8n/w8-clock/due.js`) — сбор нужен, если с прошлой отправки (static data `dispatchedAt`) прошёл хотя бы один слот по настройкам:
  - `kind = schedule` — слот этого тика;
  - `kind = catchup` — пропущенный слот, Mac спал: после пробуждения один догоняющий сбор;
  - на паузе — ничего.
- **W1** своего расписания не имеет. Его запускают W8 и кнопка «🔄 Собрать сейчас» (`kind = bot`). Параллельный запуск отсекает журнал `runs`.
- **Успешные тики** W8 не хранятся (`saveDataSuccessExecution: none`). Сборы видны в журнале `runs`.

## Страж healthchecks.io

При смене `collect.*` W7 пересчитывает OnCalendar (`onCalendar(sch)` в `schedule.js`) и запас (интервал днём + 20 мин) и отправляет их стражу:
- `POST https://healthchecks.io/api/v3/checks/<uuid>`, uuid берётся из `HC_PING_URL`;
- пауза — `POST …/pause`. Следующий пинг после «▶️ Возобновить» снимет паузу сам.

Ключ — `HC_API_KEY` в `.env` → credential «healthchecks API» (`jobHunterHcApi01`, заголовок `X-Api-Key`, `scripts/credentials.mjs`). Без ключа настройки работают, а панель пишет «⚠️ Страж healthchecks не обновлён: нет ключа API».

**Разовое действие пользователя:**
1. healthchecks.io → проект → **Settings** → **API Access** → **Create API key** (read-write).
2. В `.env`: `HC_API_KEY=…`
3. `scripts/deploy.sh`.

## Как добавить настройку

1. `n8n/shared/settings.js`: строка в `SETTINGS` (`default`, `options`).
2. Код, который её читает: `loadSettings($('Settings').all())[имя]`, а в workflow — нода `settingsNode(...)`.
3. Кнопка в разделе панели W7 (`n8n/w7-menu/settings-view.js`, раскладка в `PANEL_LAYOUTS`), callback `sc:<имя>`.
4. Эта таблица и `docs/bot-menu.md`.
